# ScreenMate 0.2.0

## New

- **Choose menu bar or Dock mode.** Turn off Show Menu Bar Icon to remove the menu bar slot and keep ScreenMate in the Dock. Click its Dock icon to reopen Settings, and use Open Controls for all layout commands. Switching takes effect immediately, without restarting. Automatic restoration keeps running after closing Settings.
- **Display-change toast.** A large black-and-mint terminal-style overlay shows the current display setup and a three-second settling progress bar. It then shows the restore result and automatically fades out after about two seconds. It never takes keyboard focus or blocks clicks. Turn it off under Open Controls → Show Display Change Toast if desired.
- All new messages support the same 15 interface languages.

## Download and install

Download **ScreenMate-0.2.0-macOS-universal.zip** under Assets, unzip, quit the old ScreenMate, and replace it in Applications. The universal app supports Apple Silicon and Intel on macOS 13+.

Layouts in `~/.screenmate/layouts.json` are preserved. Ad-hoc signing may require re-adding ScreenMate in Accessibility settings after upgrading. This build is **ad-hoc signed, not Apple-notarized**.

The accompanying `.sha256` file verifies the ZIP. Source and build instructions are in the repository. Automated tests and package checks do not replace testing actual display hot-plug behavior with your hardware.
