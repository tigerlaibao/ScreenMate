# ScreenMate 0.1.0

The first public release of ScreenMate, a free, MIT-licensed macOS menu bar utility that remembers window positions and sizes for each display setup.

## Download

- **ScreenMate-0.1.0-macOS-universal.zip** — ready-to-run app for Apple Silicon and Intel, macOS 13+.
- **ScreenMate-0.1.0-macOS-universal.zip.sha256** — SHA-256 checksum for the ZIP.

Download the ZIP under Assets. GitHub's automatically generated source archives contain source code, not the installed app.

## Install

Unzip, drag **ScreenMate.app** into **Applications**, and open it. Grant **Accessibility** access from the onboarding button. Arrange windows and save once for each setup, including laptop-only if desired. Reconnecting a known setup restores its windows after about three seconds.

The app is **ad-hoc signed and not Apple-notarized**. macOS may require **Privacy & Security → Open Anyway** for this download. No paid account is needed to build from source.

## Included

- Per-display-combination manual save/restore, automatic restore after display changes/wake.
- Different layouts for laptop-only, one-monitor, and two-monitor setups.
- Optional launch at login and optional automatic saved-layout updates, off by default.
- English by default; switch among 15 languages in the Language menu, including Simplified and Traditional Chinese.
- Local JSON storage, original icon, tests, and technical/build documentation.

## Current limits

Closed apps are skipped rather than reopened. Minimized and native full-screen windows, Spaces, desktop icons, and stacking order are outside scope. Ambiguous windows may be skipped, and apps can reject resizing. Monitor identity depends on macOS and the attached hardware. Hardware hot-plug behavior needs validation with your particular displays, docks, and applications.

See the README and `docs/BUILDING.md` for setup, source builds, verification, and troubleshooting.
