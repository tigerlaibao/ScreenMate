# ScreenMate 0.2.1

- Display-change results now stay for one second before automatically fading out.
- Restores now read back actual window positions and sizes and require two matching observations. An accepted Accessibility request alone is no longer counted as success.
- Ignored or reverted movements are retried up to three times. Stale window handles are looked up again. Pending retries stop when a new display setup or layout action takes over.

This targets compatibility with applications such as ToDesk that may apply their own window layout. The installed ToDesk window was present in saved layouts; the old implementation lacked readback verification. Automated regression tests cover asynchronous and reverted moves. Actual ToDesk restoration after monitor changes still needs validation with your active session.

Download **ScreenMate-0.2.1-macOS-universal.zip** for Apple Silicon or Intel, macOS 13+. Quit the old app and replace it in Applications. Layouts in `~/.screenmate` are preserved. This build is ad-hoc signed, not Apple-notarized; Accessibility access may need to be re-enabled after installation.
