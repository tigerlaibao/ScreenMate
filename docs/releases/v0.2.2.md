# ScreenMate 0.2.2

- Fixes a crash that could occur when the display-change overlay rendered its text on some macOS versions.
- The overlay now uses standard AppKit labels and system fonts instead of directly passing a monospaced font attribute dictionary through `NSString` drawing and CoreText.
- Window capture, matching, restoration, and saved layout data are unchanged.

Download **ScreenMate-0.2.2-macOS-universal.zip** for Apple Silicon or Intel, macOS 13+. Quit the old app and replace it in Applications. Layouts in `~/.screenmate` are preserved.

This build is ad-hoc signed. It is not signed with an Apple Developer ID and is not Apple-notarized, so Accessibility access may need to be re-enabled after installation. The fix was validated with automated tests and a universal build; real display hot-plug behavior was not hardware-tested for this release.
